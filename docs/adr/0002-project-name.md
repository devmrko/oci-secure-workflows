# OCI Secure Workflows로 프로젝트를 분리한다

날짜: 2026-11-22. 상태: 적용.

## 목적

보안을 고려한 개발·운영 작업 방법을 찾을 수 있도록 접속 도구보다 넓은 의미의 이름을 사용한다. 현재 제공하는 내용은 OCI 관리 접속, 웹/API 서비스 진입점, 외부 통신, Public IP 제거와 복구 절차다.

## 결정

프로젝트 이름과 GitHub 저장소 이름은 `oci-secure-workflows`, 문서 제목은 `OCI Secure Workflows`로 통일한다. 관리 접속·서비스 진입점·외부 통신·이전과 복구라는 작업 흐름을 기준으로 가이드와 실행 도구를 구성한다.

세션 표시 이름, 배포 파일과 ZIP 최상위 폴더도 `oci-secure-workflows`로 통일한다. 보안 정책 준수 판정이나 인증을 제공한다는 의미는 아니며 실제 finding과 환경 검증은 별도로 수행한다.
